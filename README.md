# .github

Organisation-wide files for [OMNI Tech Solutions](https://github.com/omni-tech-solutions).

- `profile/README.md` is the profile shown on the organisation page: one "blueprint" sheet in the style of [tech.omni-solutions.co](https://tech.omni-solutions.co), in a light and a dark version that follow the viewer's GitHub theme.
- `scripts/generate.mjs` draws that sheet. After changing its copy or colours, run:

```sh
node scripts/generate.mjs
```
