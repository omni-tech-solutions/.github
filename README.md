# .github

Organisation-wide files for [OMNI Tech Solutions](https://github.com/omni-tech-solutions).

- `profile/README.md` is the profile shown on the organisation page.
- `profile/assets/` holds its graphics, in a light and a dark version that follow the viewer's GitHub theme.

The graphics are drawn by a script, in the same blueprint style as [tech.omni-solutions.co](https://tech.omni-solutions.co). After changing copy or colours in it, run:

```sh
node scripts/generate.mjs
```
